HOW TO ADD YOUR REAL PHOTOS
===========================

The site currently shows placeholder images. To use your own, just drop
your files into this "images" folder using these base names:

  logo        -> your Surface Pro Cleaning logo (square works best)
  gallery-1   -> first before/after photo (e.g. patio)
  gallery-2   -> second before/after photo (e.g. driveway)
  gallery-3   -> third before/after photo (e.g. moss removal)

Any of these formats work - no renaming needed:  .webp  .jpg  .jpeg  .png
So "gallery-1.webp" OR "gallery-1.jpg" OR "gallery-1.png" will all load.

Tips:
- Keep the same base names and the site updates automatically.
- Square-ish images look best in the gallery.
- If you add a NEW format alongside an old one, the site prefers webp,
  then jpg, then jpeg, then png. To be safe, delete the old placeholder.

To view the site: double-click index.html in the folder above.
